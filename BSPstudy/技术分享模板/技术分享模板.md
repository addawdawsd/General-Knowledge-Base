## 2. 关键Log获取方法与命令

### 日志抓取命令

```bash
# 实时抓取
adb logcat -b main -b system -b crash -v threadtime > logcat.txt

# 清除后抓取
adb logcat -c
# 操作复现问题后执行抓取
adb logcat -b main -b system -b crash -v threadtime > logcat_after_clear.txt
```

### 系统重启/死机全量日志

```bash
# 如果系统能连接
adb bugreport

# 如果系统完全死机：依赖串口日志
# 确保在预量产阶段开启并捕获串口日志
```
