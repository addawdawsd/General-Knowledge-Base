## 问题标题

`[AI的angle部署]`

---

## 1. 问题关键词提取

| 分类        | 关键词                              |
| --------- | -------------------------------- |
| **功能模块**​ | `[AI]`                           |
| **现象描述**​ | `[通过部署自己的AI-agent来进行adb或者知识库共享]` |


## 2. 问题分析思路

### 实现思路

1. 主要是分为三个文件夹和两个.md文件
2. instructions文件夹放要参考的文档
3. prompts文件夹放要执行的命令
4. reademe文件夹放每次提问ai自动总结的内容，方便下次开ai的时候能够上下文联系上
5. 一个为主agent需求文件，主要放的为需要agent所要实现的功能
6. 一个为生成agent的需求文件。

### 实现方法

1. 打开生成angle的需求文件。
2. 让AI执行需求文件，使用agent功能，ai会自动跑完全程并生成一个agent文件夹。

### 使用方法
1. 将主agent文件加入对话框（在agent文件夹的一个.mk文件）。
2. 发出自己的需求。
