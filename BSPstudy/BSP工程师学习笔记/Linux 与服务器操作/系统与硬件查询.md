1. **进程与输入监控**

bash

运行

```bash
# 查看进程（简化版）
ls
# 监控输入事件（含时间戳）
getevent -tl
# 查看内核日志
dmesg
# 限制内核日志打印级别（开机停止冗余打印）
dmesg -n1
```

2. **GPIO 与引脚查询**

bash

运行

```bash
# 挂载debugfs
mount -t debugfs none /sys/kernel/debug
# 查看GPIO状态
cat /sys/kernel/debug/gpio
# 查看引脚复用情况
cat /sys/kernel/debug/pinctrl/*/pinmux-pins
# U-Boot下GPIO控制（拉高/拉低）
gpio set GPIOM_5
gpio clear GPIOM_5
```

3. **HDMI 与网络配置**

bash

运行

```bash
# 查看HDMI控制信息
dumpsys hdmi_control
# 设置WiFi国家代码（示例：TW）
echo TW > /proc/net/rtl8852be/wlan0/country_code
# 查看WiFi频道计划
cat /proc/net/rtl8852be/wlan0/chan_plan
```
