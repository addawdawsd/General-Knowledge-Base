1. **文件格式转换**

bash

运行

```bash
# 将DOS格式文件转换为Unix格式（解决换行符问题）
dos2unix 文件名
# 示例：转换system_suspend.te
dos2unix device/xxxx/common/sepolicy/vendor/system_suspend.te
# 查看文件格式
file 文件名
```

2. **压缩与解压**

bash

运行

```bash
# 压缩文件夹为zip（保留目录结构）
zip -r 压缩包名.zip 目标文件夹
# 示例：压缩out_vf_load文件夹
zip -r out_vf_load.zip out_vf_load
# 压缩文件夹为tar.gz（压缩率更高，速度更快）
tar -zcf 压缩包名.tar.gz 目标文件夹
# 示例：压缩out_vf_load文件夹
tar -zcf out_vf_load.tar.gz out_vf_load
```
3. **文件传输（SCP）**

bash

运行

```bash
# 从Windows复制文件到Linux服务器
scp -r C:\本地文件路径 用户名@服务器IP:服务器目标路径
# 示例：复制touchdrive文件夹到G720目录
scp -r C:\Users\luo\Desktop\touchdrive\* luoyong@192.168.21.54:/G720/G720_U/vendor/lango/preinstall/userFiles/

scp C:/Users/luo/Desktop/E3_75HK22_V8.4.7.bin* luoyong@192.168.21.236:/home/disk_e/luoyong/3576w/Customer/toolchains/cus_etc_firmware/XMR3576B_1V2
```
