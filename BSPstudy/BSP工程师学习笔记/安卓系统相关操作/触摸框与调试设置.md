

## 1. 触摸框开启（外挂）

以下命令用于开启触摸可视化反馈，方便调试触摸相关问题。
bash

# 显示触摸操作

adb shell settings put system show_touches 1

# 显示指针位置

adb shell settings put system pointer_location 1

# 开启触摸透传

adb shell settings put global xbh_show_pass_through_enable 1
# 看透传区域信息

dumpsys xbhManager

## 2. 触摸相关查询与配置  以下命令用于查询和配置触摸相关的系统属性和功能。`

bash

# 查看触摸框数据

adb shell getprop | grep -i touch

# 获取触摸调试属性

adb shell getprop persist.vendor.xbh.touch.debug

# 设置屏幕偏移全局变量

adb shell setprop persist.sys.xbh.screenoffset.value

adb shell setprop sys.xbh.screen.top

# 调用触摸相关函数 - 设置手掌抑制

adb shell xbhfunc setPalmRejection true/false

adb shell xbhfunc_new setPalmRejection true/false

# 强制匹配触摸框
persist.vendor.xbh.force.touch

xbhfunc XbhApi_setIICData 4 0x58 0xFF05 2 1 1
参数介绍
4: iic bus num
0x58: 27XX芯片设备地址，大部分项目基石芯片都是0x58。
0xFF05: RX PORT SWITCH RES
2：固定
1：固定
1：rx port, 1 => RX_A 2, => RX_B, 3 => RX_C, 4 => RX_D
（2）读rx port
xbhfunc_new XbhApi_getIICData 4 0x58 0xFF05 2 1 1

2. 原生IIC：
（1）写RX PORT
i2ctransfer -y 4 w3@0x58 0xFF 0x05  0x1
4: iic bus num
0x1：rx port, 1 => RX_A 2, => RX_B, 3 => RX_C, 4 => RX_D
（2）读RX PORT
i2ctransfer -y 4 w2@0x58 0xFF 0x05  r1
