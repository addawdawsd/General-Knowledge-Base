1. **进入工厂菜单**

bash

运行

```bash
# 通过ADB启动工厂菜单服务
am startservice -n com.xbh.factory.menu/.app.TvMenuWindowManagerService -e com.xbh.factory.menu.commmand com.xbh.factory.menu.commmand.factory_menu
# 串口进入工厂菜单
am startservice -n com.xbh.factory.menu/.app.TvMenuWindowManagerService -e com.xbh.factory.menu.commmand com.xbh.factory.menu.commmand.factory_menu
# 按键验证（示例：KEY_OK）
input keyevent KEY_OK
# 信源窗口控制
input keyevent 2158
```

2. **按键配置（hotkey.json）**

json

```json
{
  "key": "KEYCODE_MENU",
  "action": "startXbhSetting"
}
```
